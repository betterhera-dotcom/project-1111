# 빛이 머무는 숲 · Emerald Reverie

첫 로컬 시안입니다. `실행하기.cmd`를 더블클릭하거나 이 폴더에서 `node server.cjs`를 실행한 다음 http://127.0.0.1:4190 에 접속하세요. Node.js가 필요합니다. 카메라를 쓰려면 HTML 파일을 직접 열지 말고 이 주소로 접속하세요.

- 마우스를 움직이거나 터치하면 빛과 요정이 따라옵니다. 스페이스 키로도 숲을 깨울 수 있습니다.
- 첫 화면부터 동화풍의 고요한 숲이 보입니다. 마우스를 움직이면 인간형 요정과 에메랄드 후광이 약 0.8초에 걸쳐 나타납니다.
- 마우스가 작품 화면 안에 있으면 정지해도 빛이 유지됩니다. 화면 밖으로 나가면 약 2.5초에 걸쳐 요정과 빛이 사라지고 숲이 어두워집니다. 다시 들어와 움직이면 밝아집니다. 다른 창으로 전환할 때도 서서히 어두워집니다.
- ‘나의 얼굴로 요정 깨우기’를 누르고 카메라 권한을 허용하면 가장 크게 잡힌 얼굴을 자동 검출해 요정 얼굴에 실시간 합성합니다. 얼굴을 찾지 못하면 기본 얼굴을 보여줍니다. 인물 신원 확인이나 3D 얼굴 변환이 아닌 얼굴 영역의 타원형 영상 합성입니다.
- 같은 버튼으로 웹캠을 끌 수 있습니다. 화면을 닫으면 카메라도 종료됩니다.
- JPG, PNG, WEBP 숲 이미지를 최대 20 MB까지 선택할 수 있고 기본 배경으로 되돌릴 수 있습니다. 업로드 영상과 이미지는 브라우저에서만 처리하며 새로고침하면 초기화됩니다.
- 동작 줄이기 설정을 사용하는 환경에서는 요정의 상하 움직임과 움직이는 잔상을 줄입니다.

현재 기본 숲과 요정은 이 시안을 위해 생성한 `assets/forest-storybook-v1.png`, `assets/fairy-storybook-v1.png`입니다. 기존 숲 이미지 `assets/forest.png`는 보존했습니다. 수정 전 HTML·CSS·JS·안내문은 `.backups/before-storybook-20261110/`에 보존했습니다. `1110` 작품은 수정하지 않았습니다.

얼굴 검출: Google MediaPipe Tasks Vision 0.10.21, BlazeFace short-range float16 모델. 라이브러리·WASM·모델을 `assets/vision`에 포함해 실행 중 외부 모델 다운로드가 필요하지 않습니다. 서체만 Google Fonts를 사용하며 연결되지 않아도 시스템 서체로 작동합니다.

## 단계 범위
이번 수정은 동화풍 숲·요정 이미지, 첫 화면의 숲 표시, 화면 이탈에 따른 어두워짐, 접을 수 있는 작은 설정 창에 한정합니다. 기존 이미지 선택·웹캠 기능은 유지했습니다. 새 요정에 합성되는 얼굴 위치는 실제 카메라로 추가 확인해야 합니다. 다음 기능과 공개 배포는 사용자 요청에 따라 진행합니다.
