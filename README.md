# 프로젝트 1111 · 손짓으로 여는 AI세계

김헤라의 웹 인터랙티브 미디어 아트 작업 파일입니다.

## 작품 폴더

- `02/`: 고요한 숲과 에메랄드빛 요정 작품, 버전별 단일 HTML 파일.
- `02/emerald-forest/`: 숲·요정 작품의 HTML, CSS, JavaScript, 이미지, 얼굴·손 검출 모델, 실행 도구와 검증 자료.
- `1110/`: 멀티버스 포털 작품, 버전별 HTML, 이미지, 레퍼런스와 검증 도구.

기존 버전과 `.backups/`의 수정 전 파일도 함께 보관합니다.

## 로컬에서 확인하기

숲·요정 작품은 Node.js가 설치된 환경에서 `02/emerald-forest/실행하기.cmd`를 실행하거나, 해당 폴더에서 다음 명령어를 실행합니다.

```powershell
node server.cjs
```

브라우저에서 <http://127.0.0.1:4190>에 접속합니다. 자세한 안내는 [작품 README](02/emerald-forest/README.md)를 참고하세요.

포털 작품의 진입 파일은 `1110/포털_인터랙션.html`입니다. 브라우저에서 열어 확인할 수 있습니다.

웹캠과 사용자가 선택한 배경 이미지는 작품 실행 중 브라우저 안에서 처리합니다. 이 저장소 생성은 웹사이트 공개 배포를 포함하지 않습니다.
